# Scientific Image Classification Pipeline

A modular, reproducible deep learning pipeline built with PyTorch for scientific image classification.

## 🔬 Key Features
- **Transfer Learning Backbone:** Utilizes pre-trained `ResNet18` with custom dropout regularization.
- **Robust Optimization:** Implements `AdamW` and `ReduceLROnPlateau` scheduling.
- **Rigorous Evaluation:** Automated confusion matrix and classification report generation.
